# Firmware Repacking

## Requirements
*The following packages need to be installed*
- 7zip (for `7z` command) (could probably use other tools instead)
- squashfs-tools (for `mksquashfs` command)
- cdrtools (for the `mkisofs` command)

## Script
There is a script that does this automatically [for the R3ProII](r3proii/unpacking_and_repacking/repack.sh) and another script [for the R1](r1/unpacking_and_repacking/repack.sh). Just look at the script to see how it works, it should be pretty well commented.
